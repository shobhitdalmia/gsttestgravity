# Git sync check

Yeh file sirf GitHub sync verify karne ke liye hai — app ke code, database ya build par iska koi asar nahi.

Kaise use karein:

1. Lovable mein Project Settings > Git kholein aur agar "Reconnect" ya warning dikhe to use click karein.
2. GitHub > Settings > Applications > Installed GitHub Apps > Lovable > Configure mein check karein ki app suspended na ho aur is project ka repo access mein shamil ho.
3. Git settings mein synced branch `main` honi chahiye.
4. Phir GitHub par `main` branch ke commits refresh karein — is file ka commit dikhna chahiye. Dikh gaya to sync theek hai.

Sync theek hone ke baad yeh file delete ki ja sakti hai.
